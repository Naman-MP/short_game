FLAPPY 4'11 - joke Flappy Bird game

Files:
- index.html
- style.css
- script.js
- assets/bird.png       (your supplied bird image, unchanged)
- assets/complan.jpeg   (your supplied Complan image, unchanged)

How to run:
1. Keep the folder structure unchanged.
2. Open index.html in a browser.
3. Press SPACE, click, or tap to flap.

No image files are edited or re-encoded. CSS only controls how they are displayed in the game.
